# langShot：uTools macOS 滚动长截图插件

## Why

现有长截图工具要求用户逐页点击、采集过程中不能调整选区，并且常因缩放或有损中间处理使文字模糊。langShot 要在 uTools 中提供一条本地、高清且可恢复的长截图流程：用户框选一次后滚动或让工具自动滚动，系统持续采样、可靠去重并生成可编辑的原始像素长图。完成证明不是“能够截屏”，而是在约定应用矩阵中通过方向、固定元素、动态选区、60,000px 边界、权限失败和输出正确性的自动化与人工验收。

## What Changes

- 新建 uTools 插件外壳，负责入口、设置、编辑器、导出交互和辅助程序生命周期。
- 新建 Swift/AppKit 辅助程序，负责权限、跨应用覆盖层、选区、原始像素截屏、滚动事件、采集状态机和本地拼接。
- 建立版本化 JSON Lines IPC 协议，使插件与辅助程序可以报告进度、暂停原因、错误和导出结果。
- 以 Accelerate/vImage 和 CoreGraphics 实现无第三方大型运行库的重叠匹配、固定区域掩码、分块拼接与编码。
- 分两阶段交付：先验证完整采集链路和 PNG，再增加非破坏性标注、裁剪、JPG/WebP 和发布自动化。

## Scope

### In Scope

- macOS 10.15+，uTools 7.8.0/API v2，Intel/Apple Silicon Universal Binary。
- 屏幕录制和辅助功能权限检查、请求及可操作的修复引导。
- 任意单显示器内的选区和像素级调整。
- 手动滚动动态选区；自动滚动固定选区和滚动锚点。
- 单次向上或向下的垂直拼接、固定区域去重、低置信度暂停。
- 60,000 物理像素高度、10 分钟自动滚动保护、分块磁盘缓存。
- PNG/JPG/WebP、桌面/自定义路径、按需剪贴板。
- 截图后标注、马赛克、裁剪、撤销和重做。
- 本地元数据日志、开发构建、Universal 打包、签名和公证入口。

### Out of Scope

- 跨屏选区、横向或二维拼接、单次任务上下往返。
- 自动滚动时调整选区、采集时标注、自建系统全局快捷键。
- 云服务、遥测、截图内容日志、DRM 绕过。
- 对验收矩阵外所有应用作兼容承诺。

## Impact

- `plugin/`：uTools manifest、preload、应用 UI、编辑器、设置与 IPC 客户端。
- `native/`：Swift Package、AppKit helper、捕获/滚动/拼接/编码模块及原生测试。
- `shared/`：IPC JSON Schema、测试夹具和跨语言契约样例。
- `scripts/`：开发、Universal Binary、插件打包、签名和公证流程。
- `tests/`：Web 单元测试、协议契约测试、拼接图像夹具和人工兼容矩阵。

## Proof of Completion

1. 协议、坐标换算、会话状态机、重叠匹配、静止区域检测、分块画布和编辑操作具备可重复测试。
2. 在普通屏与 Retina 坐标夹具上，导出尺寸和像素内容与预期一致且未降采样。
3. 约 1440px 宽、60,000px 高的合成长图测试峰值内存低于 500MB，并可完成编码。
4. Chrome、Safari、微信、飞书、VS Code、预览完成向上/向下、手动/自动和固定区域场景的验收记录。
5. 权限拒绝、方向反转、低置信度、到底、超时、达到高度上限和剪贴板失败均进入规定的可恢复状态。
6. 开发包可从 uTools 7.8.0 启动；Universal 构建产物同时包含 `arm64` 与 `x86_64`，签名/公证脚本可在提供证书后执行。
