# langShot 需求澄清基线

## 文档状态

- 确认日期：2026-08-27
- 确认人：产品需求提出者
- 状态：已确认，作为规格、设计、实现与验收的输入基线
- 变更原则：任何影响用户可见行为、兼容性、权限、安全或交付范围的调整，均需重新确认并同步更新规格。

## 产品定义

- 应用名称为 `langShot`，其中 `lang` 来自用户昵称。
- 插件使用蓝白主色的长页面与向下箭头品牌图标；uTools 清单引用 256×256 PNG，项目同时保留可编辑 SVG 源文件。
- uTools 搜索关键词包含：`长截图`、`长截屏`、`滚动截图`、`langShot`。命令按大小写不敏感规则必须保持唯一，不得同时注册等价的 `langShot` / `longshot` 而产生重复搜索结果。
- 产品解决滚动长截图的三项核心问题：无需逐帧点击、手动模式可动态调整选区、保留屏幕原始像素清晰度。
- 所有截图和图片处理均在本机完成，不上传网络。

## 已确认的技术边界

1. 采用 **uTools 插件 + Swift 原生辅助程序**。
2. 原生辅助程序可以请求 macOS“屏幕录制”和“辅助功能”权限。
   - 需要系统权限时必须显示阻断式引导弹窗，逐项解释权限用途、系统设置中的授权对象、跳转入口及授权后的重新检测方式；不得只显示错误文案并假设用户知道如何操作。
3. 辅助程序生成 `arm64` 与 `x86_64` Universal Binary，最低支持 macOS 10.15。
4. 当前先支持未签名开发构建，同时提供 Developer ID 签名、公证和正式打包入口；正式发布前再注入证书。
5. 快捷键使用 uTools 自带的全局快捷键/超级面板机制，插件不额外注册 macOS 全局快捷键。

## 分阶段范围

### 里程碑 1：核心 MVP

- uTools 入口、权限检查及错误引导。
- 权限引导明确提示在 macOS 系统设置中查找 `langshot-helper`（部分系统可能显示为 `uTools`），并处理系统要求退出重开的情况。
- 单显示器智能区域推荐、自由框选、像素级调整、取消与重新框选。
- 手动滚动和自动滚动两种采集模式。
- 首次进入和默认状态选择自动滚动模式，用户可主动切换为手动滚动。
- Retina 原始物理像素捕获、无损中间帧、智能重叠检测与拼接。
- PNG 完成结果默认写入用户可管理的 `~/langshots/` 目录，首次使用时自动创建，不写入系统临时目录或桌面，并支持按需复制到剪贴板。
- 采集进度、暂停、继续、完成和丢弃。

### 里程碑 2：完整 v1

- 箭头、矩形、圆形、文字、画笔、马赛克。
- 撤销、重做和自由裁剪。
- JPG、WebP 输出及高/中/低质量档位；PNG 始终无损。
- 完整设置、错误提示、日志、签名与公证脚本和交付文档。

## 采集行为决策

### 智能选区

- 进入截图后不预先锁死固定选区；鼠标移动时实时推荐鼠标下方的截图区域。
- 推荐粒度最终覆盖应用窗口及窗口内部的网页内容区、侧栏、列表、表格、对话框和可访问控件等局部元素。
- 元素级推荐使用 macOS Accessibility 命中测试和控件树；目标应用未暴露可靠元素或没有辅助功能权限时，自动回退到鼠标下方的应用窗口。
- 单击推荐区域只表示锁定候选，不等于最终确认；锁定后仍可拖动选区、调整四边和四角，或重新自由框选。
- 用户自由拖拽框选并松开鼠标，或拖动已锁定选区完成移动/缩放并松开鼠标时，直接确认并进入后续流程；单击智能推荐候选仍只锁定，以保留后续调整能力。
- 未发生拖动时，用户点击“确认选区”或按 `Enter` 后进入后续滚动锚点或采集流程。
- 选区及滚动锚点确认阶段按 `Esc` 必须立即取消本次截图并退出遮罩；该快捷键不得依赖选区视图偶然获得键盘焦点。
- 自动滚动开始后仍按既有规则锁定选区，不允许在滚动过程中调整。

### 手动滚动

- 用户滚动鼠标或触控板，系统自动检测有效位移、采样并拼接，无需点击逐帧添加。
- 手动模式使用更高频采样和更大的位移搜索范围，允许相邻画面仅保留约 12% 的可辨识重叠；固定左右侧栏和空白边带不参与位移投票，避免把真实位移估小造成重复内容。
- 单次低置信度不得立即把当前画面设为新的拼接起点；至少先连续重采，避免瞬时动画或捕获抖动直接造成内容缺口。
- 采集中允许拖动选区边框或四角改变后续截图区域。
- 不同宽度的帧按选区的全局屏幕横坐标对齐；最终画布取所有选区的横向并集。
- 没有内容的区域保持透明；导出不支持透明的格式时填充所选背景色，默认白色。

### 自动滚动

- 开始前由用户在选区内点击一次“滚动锚点”，滚动事件始终发送到该位置。
- 开始后锁定选区，不能移动或缩放。
- 支持开始、暂停、继续、调速、完成和丢弃。
- 自动滚轮事件按锚点坐标投递到已激活目标应用的系统事件流，不得持续移动、锁定或抢夺用户的鼠标指针；用户始终可以把鼠标移出选区。
- 进入采集后，截图遮罩必须切换为不激活、不抢焦点的置顶面板；滚轮通过锚点坐标投递到系统事件流，确保 Chrome、Safari、Electron/WebView 等目标能实际响应，同时不得改变鼠标指针位置。
- 自动滚动必须采用反馈闭环：每次只滚动一小步，等待页面稳定并完成截帧、重叠识别和无损帧入库后，才允许发送下一次滚动；不得由独立定时器在上一帧仍处理中时继续滚动。
- 自动模式默认每步 2 行；一旦匹配不确定立即降为每步 1 行并在当前位置重采，连续高置信度后才可恢复 2 行。自动模式不得通过丢弃失败帧、直接把当前画面设为新起点来恢复。
- 采集时始终显示独立且可点击的状态控制卡，至少包含“暂停/继续”“完成”“取消”，控制卡不能被全屏遮罩阻断。
- 目标应用重新获得前台焦点后，蓝色截图选框、采集状态和控制卡必须继续置顶可见，不得因 helper 失去激活状态而消失。
- 自动滚动默认最长 10 分钟，允许在设置中缩短；达到时暂停而非直接丢失内容。

### 方向和结束

- 单次任务支持向上或向下的垂直滚动，开始后锁定方向。
- 检测到反向滚动时暂停并提示；不支持单次上下往返，也不支持横向拼接。
- 首次有效滚动前没有检测到位移时，插件必须继续在后台尝试，不得暂停、显示“点击继续”或自动完成；如果用户主动完成，可在结果页非阻塞提示结果可能只包含首屏。
- 已检测到至少一次真实滚动位移后，连续静止只能作为内部参考，不得自动完成或跳转结果页，也不得插入要求用户继续的识别暂停；常规会话只由用户点击“完成”或按 `Enter` 结束，硬性高度与时长上限除外。
- 第一次按 `Esc` 暂停并显示“继续 / 完成 / 丢弃”；暂停状态再次按 `Esc` 才丢弃。
- `Enter` 直接完成当前采集；快捷键必须在截图目标应用持有焦点时仍能生效，不能只依赖插件窗口内部事件。
- 最终长图最大物理像素高度为 60,000px；达到上限时暂停并提示完成。

## 拼接规则

- 自动检测垂直重叠区域并消除重复内容。
- 重叠候选必须满足最小重叠比例且相对其他候选具有足够唯一性；重复纹理导致多个位移近似同分时不得把错误大位移作为新增内容追加。
- 自动识别吸顶导航、固定输入框、固定标签栏等静止区域，最终只保留一份。
- 匹配置信度不足时先在后台原地重采，整个采集流程不得因此暂停或要求用户点击继续。自动模式必须停在当前位置继续识别，不能跳过失败帧后继续滚动；手动模式因用户滚动不可回控，只有连续多次失败后才允许重新同步，并须在结果页显示非阻塞完整性提示。
- 自动模式额外使用最近有效帧的位移中位数预测下一帧滚动距离；低于常规阈值但与历史位移一致的候选可在更严格的最低置信度下接受，明显跳变或重复纹理候选仍须拒绝。
- 尚无历史位移的首段允许接受“置信度高于安全下限且位移不超过探针高度四分之一”的小步弱匹配；若连续六次原地重采仍失败，可追加一次最小 1 行恢复探测但继续以最后有效帧为基准，最多六次，避免等待用户手动滚动才能启动。
- 内部使用分块存储和缩略预览，不能为编辑预览而降低最终输出分辨率。

## 编辑、保存与剪贴板

- 标注只在长图生成完成后进行，不在采集覆盖层中标注。
- 自动复制是持久化设置，默认关闭。
- 用户点击复制后必须同时显示高层级成功提示和按钮状态反馈，不能让结果面板遮挡反馈。
- 复制成功并短暂显示反馈后自动退出 langShot 插件页面。
- uTools 再次进入 langShot 时必须重置为新的默认首页：自动模式、向下方向、无旧预览、无旧路径、复制按钮可用；不得显示上一次完成页面。旧 helper 的延迟退出事件不得断开新进入页面创建的 helper 连接。
- 超大图片复制前提示；复制失败时仍可保存 PNG，且不能丢失当前编辑结果。
- 截图完成后的 PNG 保存在 `~/langshots/`；langShot 每次启动时删除修改时间超过 7×24 小时且由 langShot 命名的截图，保留近期文件和目录中的其他用户文件。

## 兼容与验收

- 正式验收应用：Chrome、Safari、微信、飞书、VS Code、macOS 预览。
- 其他应用采用通用兼容策略，但不承诺全部通过。
- 用户可在任意一块显示器上截图，但单次选区不得跨越显示器边界。
- 每块显示器按其原始 DPI 捕获；Retina 图像不降采样。
- 10 帧/秒、CPU 小于 30%、内存小于 500MB 的性能目标，以当前 Apple Silicon 开发机和约 1440px 宽选区为严格验收基准；Intel 以功能兼容为主。

## 非目标

- 跨显示器选区或跨 DPI 拼接。
- 横向滚动、二维画布或单次上下往返。
- 自动滚动过程中调整截图区域。
- 采集过程中进行标注。
- 插件自行注册系统全局快捷键。
- 云同步、云存储或任何截图上传。
- 保证所有第三方应用兼容。
- 绕过 DRM 或系统保护内容的黑屏限制。
